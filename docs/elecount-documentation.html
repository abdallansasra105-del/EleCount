1. نظرة عامة

تطبيق Android باللغة العربية (RTL) لإدارة استهلاك الكهرباء المنزلي. يعمل مع Appwrite كقاعدة سحابية، والعملة الافتراضية شيكل.

البندالقيمة
اسم الحزمةcom.example.elecount
اللغةJava
الحد الأدنى AndroidAPI 24 (Android 7.0)
التصميمMaterial Design — لون رئيسي برتقالي #FF9800
التخزينسحابة (Appwrite) + SharedPreferences للجلسة

المميزات

  • تتبع الأجهزة وتشغيلها/إيقافها مع مؤقت حي وتكلفة لحظية
  • حفظ سجل كل جلسة في usage_records
  • إحصائيات: السجلات، أغلى/أرخص جهاز، التكلفة الإجمالية
  • محاكي تكلفة بدون تسجيل دخول
  • ملف شخصي: تعديل الاسم والصورة
  • تصنيفات مخصصة (مطبخ، صالة، …)

2. البنية البرمجية

app/ ├── MainActivity.java ├── LoginActivity.java ├── fragments/ → Home, Devices, Simulator, Settings, Categories ├── adapters/ → Device, Category, UsageRecord ├── models/ → User, Device, Category, UsageRecord └── Hellper/ → DataManager, AppWriteConn, UserSession, …

تدفق البيانات

Fragment → DataManager → AppWriteConn → Appwrite Cloud ↓ UserSession (SharedPreferences)

3. تخطيط التنقل

LoginActivity ──► MainActivity │ ┌───────────────┼───────────────┐ ▼ ▼ ▼ HomeFragment DevicesFragment SimulatorFragment │ │ │ └───────────────┴───────────────┘ │ SettingsFragment → CategoriesFragment

الشريط السفلي: الرئيسية | الأجهزة | المحاكي | الإعدادات (الأسماء ظاهرة دائماً)

4. تخطيط الشاشات

4.1 LoginActivity — تسجيل الدخول

activity_login.xml + LoginActivity.java

  • تسجيل دخول / إنشاء حساب / دخول كضيف
  • حفظ الجلسة عبر UserSession

4.2 MainActivity — الهيكل

  • headerContainer — Toolbar برتقالي
  • fragmentContainer — محتوى الشاشة
  • bottomNavigation — التبويبات

4.3 HomeFragment — الرئيسية

العنصرالوظيفة
totalCostTextسجلات + جلسات حية
runningDevicesTextعدد الأجهزة الشغّالة
currentConsumptionTextمجموع kW
recordsSessions/Energy/Costإحصائيات السجلات
mostExpensive / cheapestأغلى وأرخص جهاز
runningDevicesRecyclerالأجهزة العاملة

4.4 DevicesFragment — الأجهزة

  • قائمة كل الأجهزة + زر (+)
  • بطاقة: صورة، مؤقت، تكلفة، تشغيل/إيقاف، سجل
  • عند الإيقاف → UsageRecord في السحابة

4.5 SimulatorFragment — المحاكي

  • جهاز + مدة + وحدة → تكلفة وkWh متوقعة

4.6 SettingsFragment — الإعدادات

  • بطاقة الملف → تعديل اسم وصورة
  • التصنيفات، سعر kW، دخول/خروج

4.7 CategoriesFragment + DeviceHistoryDialog

  • CRUD للتصنيفات
  • نافذة سجل جلسات جهاز واحد
